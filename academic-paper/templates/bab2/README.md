# PANDUAN LENGKAP & ARTIFAK PENULISAN BAB II (KAJIAN PUSTAKA)

Folder ini memandu perancangan **Bab II (Kajian Pustaka dan Kerangka Berpikir)** agar tidak menjadi sekadar salin-tempel definisi buku teks.

---

## 1. Komponen Wajib Bab 2
1. **2.1 Penelitian Terdahulu (Literature Review)**:
   - Menggunakan Matriks Komparatif 13 Kolom (`/skripsi-matriks`).
   - Berisi 5–20+ artikel jurnal mutakhir (minimal 80% jurnal 3–5 tahun terakhir).
   - Dilengkapi sintesis naratif mengenai posisi kebaruan (*gap & novelty*) penelitian Anda.
2. **2.2 Landasan Teori (Hierarki 3 Level)**:
   - **Grand Theory**: Teori payung abstrak fundamental (contoh: *Resource-Based View*, *Theory of Planned Behavior*, *SWEBOK Architecture*).
   - **Middle-Range Theory**: Teori perantara variabel / jembatan konsep (contoh: *Technology Acceptance Model (TAM)*, *Agency Theory*, *Scrum Framework*).
   - **Applied / Operational Theory**: Teori operasional yang menjadi pisau analisis langsung di Bab 4 (contoh: *Indikator Perceived Usefulness*, *Rasio Likuiditas*, *Black-Box Test Design*).
3. **2.3 Kerangka Berpikir (Diagram Mermaid)**:
   - Visualisasi alur berpikir logis masalah $\rightarrow$ pisau analisis $\rightarrow$ solusi.
   - Menggunakan sintaks standar Mermaid agar ter-render rapi di Markdown maupun naskah akhir.
4. **2.4 Hipotesis Penelitian (Khusus Kuantitatif)**:
   - Perumusan hipotesis alternatif ($H_a$) dan hipotesis nol ($H_0$) berbasis deduksi teori.
