# PANDUAN LENGKAP & INTEGRITAS BAB IV (HASIL & PEMBAHASAN / IMPLEMENTASI & PENGUJIAN)

Folder ini mengatur penyusunan **Bab IV** agar argumen ilmiah kuat dan tidak terjadi klaim kosong (*unsupported claims*).

---

## 1. Varian Klasik: Hasil Penelitian dan Pembahasan
1. **4.1 Gambaran Umum Objek Penelitian**: Profil instansi, responden, atau subjek penelitian.
2. **4.2 Deskripsi Data & Hasil Analisis**:
   - Penyajian statistik deskriptif atau reduksi data wawancara.
   - Uji prasyarat analisis (normalitas, multikolinearitas, heteroskedastisitas).
   - Pengujian hipotesis (uji-t, uji-F, nilai koefisien determinasi $R^2$, path coefficient).
3. **4.3 Pembahasan Hasil Penelitian (Triangulasi 3 Arah)**:
   - Dilarang hanya membaca ulang tabel angka.
   - Wajib membenturkan: **Temuan Data Empiris vs Teori (Bab 2) vs Hasil Riset Jurnal Terdahulu**.
   - Menjelaskan *mengapa* hipotesis diterima/ditolak dan apa arti praktis temuan tersebut.

## 2. Varian IT / Software Engineering: Implementasi dan Pengujian Sistem
1. **4.1 Lingkungan Implementasi**: Spesifikasi hardware, software stack, database engine, hosting/server.
2. **4.2 Implementasi Sistem & Modul Utama**: Tampilan antarmuka fungsional dan snippet modul kode penting.
3. **4.3 Hasil Pengujian Black-Box**: Tabel hasil uji partisi ekivalensi (Input $\rightarrow$ Output Diharapkan $\rightarrow$ Hasil Aktual $\rightarrow$ Status Lulus).
4. **4.4 Pengujian Usabilitas Pengguna (SUS & UAT)**: Skor kelayakan (target minimal grade B / SUS score $> 68$).
5. **4.5 Evaluasi Kinerja Beban / Benchmarking (Bila Ada)**: Respon time, latency, throughput query.
