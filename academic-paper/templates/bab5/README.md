# PANDUAN LENGKAP & KONSISTENSI BAB V (KESIMPULAN DAN SARAN / PENUTUP)

Folder ini memastikan penutupan skripsi (**Bab V**) benar-benar menjawab rumusan masalah tanpa menambah klaim baru di luar data.

---

## 1. Sub-Bab Wajib Bab 5
1. **5.1 Kesimpulan**:
   - Wajib menjawab **1-to-1 konsisten** terhadap Rumusan Masalah ($RQ_1, RQ_2, RQ_3$) dan Tujuan Penelitian di Bab 1.
   - Bukan mengulang angka statistik mentah, melainkan menyajikan kesimpulan epistomologis (*natijah* / temuan substantif).
2. **5.2 Implikasi Penelitian**:
   - Implikasi Teoretis: Kontribusi penelitian terhadap pengembangan keilmuan terkait.
   - Implikasi Praktis / Manajerial: Rekomendasi kebijakan yang dapat diterapkan langsung oleh stakeholder.
3. **5.3 Keterbatasan Penelitian**:
   - Pengakuan jujur atas limitasi sampel, metode, rentang waktu, atau parameter teknis (mencegah overclaim).
4. **5.4 Saran**:
   - Saran operasional untuk objek penelitian / instansi terkait.
   - Saran akademik konkret untuk peneliti selanjutnya (*future work*).
