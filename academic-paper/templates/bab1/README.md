# PANDUAN LENGKAP & SCAFFOLDING PENULISAN BAB I (PENDAHULUAN)

Folder ini berisi seluruh instrumen, scaffolding kalimat, checklist mandiri, dan template baku untuk penyusunan **Bab I (Pendahuluan)** Skripsi S1.

---

## 1. Struktur Folder Bab 1
```text
academic-paper/templates/bab1/
├── README.md                          <- Panduan ini
├── template.md                        <- Template naskah Bab 1 siap pakai
├── scaffolding_latar_belakang.md      <- Panduan kalimat alinea demi alinea (Umum -> Khusus)
└── checklist_bab1.md                  <- Rubrik audit kelayakan Bab 1 sebelum bimbingan
```

---

## 2. Peta Sub-Bab Standar Bab 1
1. **1.1 Latar Belakang Masalah**:
   - Pola Funneling (Piramida Terbalik: Fenomena Makro $\rightarrow$ Data Realita Meso $\rightarrow$ Research Gap Mikro).
   - Kalimat pembuka mempertemukan Objek Material dan Objek Formal.
   - Aturan Anti-Klise: Tidak menggunakan kata "penting/sangat penting", melainkan membeberkan risiko konkret jika masalah tidak diselesaikan.
2. **1.2 Rumusan Masalah**:
   - Diawali kalimat deklaratif baku: *"Terdapat [kesenjangan] antara ... dan ... sehingga ..."*.
   - Minimal 3 Pertanyaan Penelitian ($RQ_1, RQ_2, RQ_3$) terstruktur dari Umum ke Khusus.
3. **1.3 Tujuan Penelitian**:
   - Pemetaan konsisten 1-to-1 dengan $RQ_1, RQ_2, RQ_3$ menggunakan Kata Kerja Operasional (KKO) analitis tinggi.
4. **1.4 Manfaat Penelitian**:
   - Manfaat Teoretis (pengembangan disiplin ilmu).
   - Manfaat Praktis tepat 3 kelompok sasaran (organisasi/tempat penelitian, akademisi/peneliti selanjutnya, masyarakat luas).
5. **1.5 Batasan Masalah / Ruang Lingkup**:
   - Menetapkan batasan modul, subjek, periode, atau teknologi agar penelitian terfokus.
