# PANDUAN LENGKAP & SPESIFIKASI BAB III (METODOLOGI / ANALISIS DESAIN)

Folder ini berisi pedoman operasional penulisan **Bab III**, mencakup dua varian tradisi besar:

---

## 1. Varian Klasik: Metodologi Penelitian (Sosial, Bisnis, Pendidikan, Hukum, Kesehatan)
1. **3.1 Desain Penelitian**: Pendekatan (kuantitatif / kualitatif), metode (survei, eksperimen, studi kasus, yuridis normatif).
2. **3.2 Populasi & Sampel / Subjek & Informan**: Teknik sampling (probability / purposive sampling) dan penentuan ukuran sampel (Slovin, Roscoe, saturasi data).
3. **3.3 Operasionalisasi Variabel**: Tabel dimensi, indikator, skala pengukuran (Likert / Guttman), dan nomor butir kuesioner.
4. **3.4 Teknik Pengumpulan Data**: Kuesioner, wawancara mendalam, observasi, studi dokumen.
5. **3.5 Uji Instrumen**: Uji validitas (korelasi Pearson / CFA) dan reliabilitas (Cronbach's Alpha $> 0.70$).
6. **3.6 Teknik Analisis Data**: Analisis statistik (uji asumsi klasik, regresi berganda, SEM-PLS) atau analisis tematik kualitatif.

---

## 2. Varian Rekayasa Perangkat Lunak: Analisis dan Desain Sistem (Informatika / SI / RPL)
1. **3.1 Metodologi Pengembangan**: Agile / Scrum, Waterfall, Prototyping, atau R&D model.
2. **3.2 Analisis Kebutuhan**: Kebutuhan Fungsional (FR) & Non-Fungsional (NFR standard FURPS+).
3. **3.3 Pemodelan Arsitektur & UML (Diagram Mermaid)**: Use Case, Activity, Sequence, dan Class Diagram.
4. **3.4 Perancangan Basis Data & Antarmuka**: Entity Relationship Diagram (ERD) dan wireframe UI/UX.
5. **3.5 Rencana Pengujian**: Skenario pengujian kotak hitam (*Black-Box testing*), System Usability Scale (SUS), dan UAT.
